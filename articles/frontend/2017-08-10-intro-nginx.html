            # 常用命令

            • start nginx.exe 启动
            • nginx -s stop 快速关闭
            • nginx -s quit 优雅关闭（不接受新的请求，等待旧的请求完成后再关闭）
            • nginx -s reload 重新加载配置文件
            • nginx -s reopen 重启日志文件

            # 应用场景

            • 动静分离

            动静分离将网站静态资源（HTML，JavaScript，CSS，img等文件）与后台应用分开部署，提高用户访问静态代码的速度，降低对后台应用访问。这里我们将静态资源放到nginx中，动态资源转发到tomcat服务器中。

            • 反向代理

            反向代理（Reverse Proxy）方式是指以代理服务器来接受internet上的连接请求，然后将请求转发给内部网络上的服务器，并将从服务器上得到的结果返回给internet上请求连接的客户端，此时代理服务器对外就表现为一个反向代理服务器。

            • 负载均衡

            负载均主要衡解决网络拥塞问题，提高服务器响应速度，服务就近提供，达到更好的访问质量，减少后台服务器大并发压力。主要根据算法策略将请求分摊到多台后台服务器处理。

            一般来说是设定http服务器，利用它的反向代理功能提供负载均衡支持

            # demo

            • 将静态文件放在nginx的html文件夹中，也可以放到其他地方
            • 配置nginx.conf

            nginx.conf 文件配置

            #user  nobody;
# worker_processes 工作进程，可有多个
worker_processes  1;

#error_log  logs/error.log;
#error_log  logs/error.log  notice;
#error_log  logs/error.log  info;

#pid        logs/nginx.pid; 主进程id存放文件

events {
    worker_connections  1024;
}


http {
    include       mime.types;
    default_type  application/octet-stream;
    sendfile        on;
    keepalive_timeout  65;
#	upstream backend {
#		server 10.10.4.110 weight=1;
#		server 10.10.4.110 weight=1;
#	}
    server {
        listen       9090;
        server_name  localhost;
        location / {
            # 设置主机头和客户端真实地址，以便服务器获取客户端真实IP
            # proxy_set_header Host $host;
            # proxy_set_header X-Real-IP $remote_addr;
            # proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
            # 禁用缓存
            # proxy_buffering off;
            # 设置反向代理地址
            # proxy_pass，填写真实地址
            proxy_pass http://localhost:9099;
        }

    }
	server {
        listen       9099;
        server_name  localhost;
        location / {
            root   F:/nginxhtml;
            index  index.html index.htm;
        }
        error_page   500 502 503 504  /50x.html;
        location = /50x.html {
            root   html;
        }

    }
    server {
        listen       9091;
        server_name  localhost;
        location / {
            root   F:/nginxhtml/project1;
            index  index.html index.htm;
        }
        error_page   500 502 503 504  /50x.html;
        location = /50x.html {
            root   html;
        }

    }

}
